Connector 0.8.4 refreshes update candidates after verified plugin and theme updates before publishing the completion inventory.
If a provider check fails, stale candidates are discarded and later updates remain safely held for review.
Reports include bounded failure categories without package URLs, credentials or raw provider messages.
Self-updates use the official release, preserve pairing and verify the installed version in a later WordPress request. An interrupted installation is never repeated blindly.
The compatible dashboard and service must be deployed before installing this version. Existing content and update permissions remain in place.
