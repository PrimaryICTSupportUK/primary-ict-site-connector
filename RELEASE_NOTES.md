# Site Connector 0.8.0

- Adds a single connection-details block, expiry recovery and a validated return link for guided dashboard setup.
- Supports the reviewed native commercial-theme update protocol with exact versions, approved package hosts and preserved parent/child selection.
- Preserves existing pairing, the shared Primary ICT Support menu, content permissions, maintenance jobs and the normal GitHub updater.

Requires the compatible service and reviewed migrations, deployed before this release. The dashboard's guided features have a separate rollout switch; installing this connector does not enable services, schedules or chat access.

Install this exact release ZIP using the normal WordPress GitHub updater. Do not uninstall the existing plugin: pairing must remain in place. Connector self-updates are deliberately excluded from its dashboard job queue.
