Site Connector 0.8.1 adds administrator-started database preparation for content editing. Before starting, confirm a restorable database backup and that no other updates are running. The connector uses WordPress maintenance mode, shows completed-table progress and provides an interruption check. Timing varies with table size, server load and other activity; other systems and already-running requests can bypass WordPress maintenance. Existing pairing and permissions are preserved. Requires the compatible dashboard and database migration before installation. Preparation never starts automatically.
